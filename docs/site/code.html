The change explorer

On reading every file the run changed, and walking the change in the order it runs.

Every file the run changed is here, whole, with the line numbers the editor shows. Pick a file, or walk a trail: one flow told declaration by declaration, from where it starts to what it hands on. Four trails train the parts of the verdict and four run them. Two sign an image and match a crop of it, and one is the pruning study.

Pasting works. Copy a function name, a signature line or a whole body into the box. The page opens the file at that declaration, with what it calls and what calls it.

Those lists were matched by name and argument labels when the page was built, not by a compiler, and each says how sure it is. Copy a line as File.swift:21, and the editor's Open Quickly lands on the same line.
