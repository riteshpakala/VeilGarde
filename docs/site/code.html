The change explorer

On reading every file the run changed, and walking the change in the order it runs.

Every changed file is here, whole, with the editor's line numbers: pick one, or walk a trail, one flow told declaration by declaration in the order it runs. Two trails train the fusion head and the specialist stack and two run them to the verdict; two sign an image and match a crop of it. Paste a name, a signature line or a whole body into the box to open that declaration with what it calls and what calls it. Calls are matched by name and argument labels, not by a compiler, and each says how sure it is; Copy line gives File.swift:42 for the editor's Open Quickly. The ML explorer walks the same code as machine learning, model by model.
