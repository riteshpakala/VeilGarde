The self-check

On every check the site can make in the browser, run when this page opened.

The checks below hold the data to itself and to the code it embeds. Every declaration's lines lie inside its file, every signature line holds its keyword, and the ids this page derives equal the build's. Every call edge joins two declarations with a tier, and every trail entry resolves and still holds its anchor.

A page opened from disk cannot read the repository, so the comparison with the working tree runs in docs/site/src/check.py, which fails when a file changed after the build. That script opens this page in Chrome and fails if any check below fails.
