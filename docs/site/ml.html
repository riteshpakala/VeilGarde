The ML explorer

On how each shipped model learns and decides, and how the models together reach the two verdicts.

Every model VeilGarde ships is here, told as machine learning: what it learns from, the features it reads, the algorithm and why it was chosen, the fit, the calibration, and what it adds to the verdict. Six trails follow one model each.

The seventh follows the two verdicts the result keeps, the majority and the weighted. Each of its steps says which path it is on, so the place where the trail crosses from one to the other is plain. It ends with the evidence that each part is needed, and the commands that test it again.

Each step opens with a primer for a reader new to the idea, then the note on the code, then a deeper line for a practitioner with the trade-off and the measured numbers. The depth control shows the first two, the last two, or all three, and remembers the choice.

Every number on a card is read from the shipped bundle when the page opens, or names the ledger entry, the test or the chapter it came from. Each step links to its twin on the change explorer, which walks the same flow in the order the code runs. What the marks mean is one click away, under the trail grid.
